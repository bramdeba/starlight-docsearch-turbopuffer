---
title: Multilingual sites
description: Index and search each language separately.
---

On a multilingual Starlight site, each language is indexed into its own namespace, and readers only see results in the language they are browsing.

Add a `{lang}` placeholder to the namespace. It is replaced with each locale’s language tag in lowercase:

```js title="astro.config.mjs"
starlightDocSearchTurbopuffer({
	namespace: 'my-docs-{lang}', // my-docs-en, my-docs-fr, my-docs-pt-br, …
});
```

The plugin requires the placeholder when your site has more than one locale.

## Language-aware keyword search

Keyword search uses a stemmer and stopword list for each language, so `installer` and `installation` match in French. The plugin picks the turbopuffer language from each locale’s language tag. turbopuffer supports Arabic, Danish, Dutch, English, Finnish, French, German, Greek, Hungarian, Italian, Norwegian, Portuguese, Romanian, Russian, Spanish, Swedish, Tamil and Turkish. Other languages are indexed without stemming.

Override the language per locale with `fullTextSearch.language`:

```js
starlightDocSearchTurbopuffer({
	namespace: 'my-docs-{lang}',
	fullTextSearch: { language: { 'zh-cn': 'english' } },
});
```

## Embeddings

The default embedding model, `baai/bge-m3`, is multilingual. If you choose a different model, make sure it supports all your languages.

## Untranslated pages

Starlight shows untranslated pages in the default language under each locale. These pages are indexed in each locale’s namespace, so readers can find them in any language.
